# BIRD Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for inline execution. This is a new artifact folder in a literature workspace, not an existing software branch; no Git commit/worktree workflow is required.

**Goal:** 完成期刊版 BIRD 的可运行参考实现与中文方法说明。

**Architecture:** 独立 hashgrid + 双向 DVF + 双图像头；物理射线积分和明确梯度所有权；CPU 可验证。

**Tech Stack:** Python, PyTorch, NumPy, pytest。

**Spec:** ../../../SPEC.md

## Global Constraints

期刊版为基准；论文参数与补全假设分开；不声称官方代码/数据指标复现；保留原资料。

## Review Focus

1. 射线长度与归一化坐标混用：常数体积分测试。
2. 配准错误冻结输入梯度：forward-only gradient 测试。
3. FFT 丢相位或 chunk 改变损失：手算/乱序/分块测试。
4. 文件数据形状和时间域错误：拒绝非法输入测试。
5. checkpoint resume 改变 RNG 或优化 schedule：连续/恢复等价测试。
