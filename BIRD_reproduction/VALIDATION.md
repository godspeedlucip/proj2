# 实际验证记录

日期：2026-11-16。初版验证环境：Windows；Python 3.14.3；PyTorch 2.11.0 CPU；NumPy 2.4.4；pytest 8.4.2；scikit-image 0.26.0。该 Python 环境无 CUDA；后续在独立 conda 环境发现并实际验证了 CUDA/TIGRE，见 [PIG_VALIDATION.md](PIG_VALIDATION.md)。以下16项是初版历史记录，合并后共30项测试。

## 已完成检查

1. **16项自动测试通过**，覆盖插值手算及梯度、双图像路径梯度、完整复数 FFT 手算/排序、仿射逆一致性、时间二阶差分、配准仅 forward 参数更新、射线常数体积分/平行错过、分块输出与梯度、两种数据接口、坏输入、恢复与推理、无后缀输出防覆盖、float32 溢出和恢复日志修复、指标手算。
2. **完整 paper 配置实例化与全损失反传**：44,335,916 参数；4个查询点输出 `mu/mu_tp=[4,1]`，`backward/static=[4,3]`；损失和所有已产生梯度均有限。记录：`runs/paper_profile_check.json`。这是 full-capacity 网络检查，不是64000步完整训练。
3. **小型合成场景真实训练100步**：24视角×16×16探测器，共6144条射线。生成投影用96个采样点/射线，训练用24个；没有使用图像或 DVF 真值监督。配置为 `configs/smoke.json`。
4. **训练后推理**：时刻0、0.5、1秒；输出 `mu` 形状 `[3,24,24,24]`，DVF形状 `[3,24,24,24,3]`，均有限。结果：`runs/smoke/reconstruction.npz`。
5. **恢复一致性**：相同CPU、配置、种子下，连续4步与2步+恢复2步的所有模型 state_dict 张量逐元素相等。

第一行比较的是不同随机 batch，不能作为同一固定数据上的精确降幅；后两行在同一完整训练扫描上计算，避免只看抽样波动。它们仍是**训练集投影拟合**，不是保留集或真实动态体重建精度。欠定问题中投影拟合改善也可能伴随错误的运动/图像分解。

逐步日志、checkpoint、固定投影评价 JSON 和形状统计分别保存于 `runs/smoke/history.jsonl`、`checkpoint.pt`、`projection_fit.json`、`run_summary.json`。checkpoint 是本次合成场景的权重，不能用于真实患者的直接诊断重建。

## 独立审查与修复

一名独立 reviewer 只读检查了 spec、代码、期刊公式并独立运行12项初版测试，确认 Eq16/20/21/22/23–26 的关键路径一致。发现并通过先失败后通过的测试修复：

- NumPy 自动追加 `.npz` 可能绕过无后缀路径的防覆盖检查：现在先规范化实际输出路径，生成器/推理都受保护。
- float64 有限几何转换为 float32 后可能成为 inf：现在检查转换后有限性，并稳定归一化方向。按输入合同作为需修正的正确性问题处理。
- 两次 checkpoint 之间崩溃会留下较新的/残缺日志：恢复前留备份并截到 checkpoint 步数，避免重复或不合法 JSON 记录。

独立审查没有评判未提供的数据指标、CUDA性能、作者未公开超参或后续撰写的说明文档；这些限制保留为本报告的未验证项，不把未审查部分描述为通过独立审查。没有遗留未处理的已确认代码正确性问题。

## 明确未验证

- 真实患者、实际scanner原始数据或 XCAT 数据；论文PSNR/SSIM；多随机种子稳定性。
- 64000步训练收敛、临床三维尺度的速度/显存；后续新增的有限规模CUDA验证范围单独记于 PIG_VALIDATION。
- 与作者源代码/tiny-cuda-nn 的逐位一致性。作者代码未确认可获得。
- 严格微分同胚与全域无折叠：实现的是软 cycle-Jacobian 正则，数学测试不能替代全域保证。
