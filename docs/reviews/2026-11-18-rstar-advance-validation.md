# RSTAR4D 猪心轮廓消融实施验证

工作分支为 `rstar-advance`，基础提交为 `a64867a`。实现和验证对应 [Spec v1.4](../superpowers/specs/2026-11-18-rstar4d-cardiac-contour-ablation-design.md) 及[实施计划](../superpowers/plans/2026-11-18-rstar4d-cardiac-contour-ablation.md)。

## 软件验证

- `python -B -m unittest discover -s tests -v` 通过 57 项。全关 Stage II 与原入口在同一 W 和 C 上得到相同的 FP32 输出、损失及具名参数梯度。跨 C 真值位移体模的整幅与 W 窗口计数相等，LNCC 一致。所有八组均完成前向、反向和严格权重重载。
- `python -B -m validation.cardiac_smoke --out runs/cardiac-validation/smoke-delivery` 通过。八组复用同一 Stage I 权重，分别完成两轮 Stage II、一次续训、滑窗推理和独立阈值轮廓评价，两轮采样哈希均在八组间一致。全开体模两轮均命中整心外边界和 LV 边界。
- 在宽 112 vox 的合成序列上，用体模全开 checkpoint 比较整幅和实际截断上下文的滑窗。内部 MAE 为 `1.17e-9`，重叠接缝 MAE 为 `1.12e-9`，接缝最大绝对误差为 `9.78e-9`，单位与输出衰减强度相同。
- 在 TIGRE 投影体模 `phantom_0` 上分别对相位 1 的 `[0,1,49]` 和 `[50,51,99]` 两组视角执行了稀疏 FDK。两份输出的 prior、参考图、有效域及其余状态逐值相同。相位 1 稀疏输入和角度摘要均有差异。交换摘要推理生成了不同的摘要哈希，并在预测清单记录实际/编码索引及交换标记。
- 另核对了带平移的 NIfTI 标注落点、来自清单的 mask 文件变更导致缓存失效，以及可选表面项的固定分母和越界梯度。体模上的 prior 错配诊断未找到同时满足单候选、有效细点数和值幅匹配的点，工具报告有效点数为零。
