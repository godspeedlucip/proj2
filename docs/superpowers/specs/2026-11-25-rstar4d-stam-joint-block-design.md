# 原版 RSTAR4D 接入完整 STAM Joint Block 实现与实验 Spec

版本 1.1 · 2026-11-25 · 待实现与验证

**主方案选用 STAM 图 2 的一个完整 Joint Block。** 在原版 RSTAR4D Stage II 编码器与解码器交界处接入一次，保留块内的空间适配、时间适配及融合层。研究问题是，在 RSTAR 已有 XY/Z/T 卷积和多相位输入的基础上，两种注意力联合使用能否进一步降低运动边界的重建误差。[STAM 图 1–2、表 4](https://doi.org/10.1016/j.bspc.2025.108480) · [RSTAR4D §2.2](https://arxiv.org/html/2403.16361v4)

交付范围为原版 RSTAR4D 的可选 Stage II 模块、训练与推理入口、检查点兼容和动物级配对评估。发布开关默认关闭。空间与时间双分支作为一个整体接入一次，仅时间分支用于消融。启用模块后，**全程冻结 RSTAR** 和 **从第一个优化步就联合训练 RSTAR** 是两种独立策略。两者均可直接从同一原版 Stage II 检查点启动。“先冻结再解冻”是可选的第三种策略。

## 1. 模块职责

假设目标心动相位有一条亮纹横穿左室壁。空间分支能在该相位的同一层面比较各个区域，使受污染位置可以利用周围室壁的走向。时间分支在同一网格位置比较不同相位，使目标位置可以利用条纹较轻时的局部表现。两种证据互补。尤其当心脏快速收缩时，同一空间位置在另一相位可能已经落入血池，目标相位自己的空间结构就格外重要。两支并行计算，随后融合；它们不显式配准组织，也不强制对注意力权重赋予解剖含义。

| Joint Block 中的部件 | 主方案保留的结构 |
|---|---|
| 空间适配 | 固定相位和轴向层面，在平面图像块之间做多头自注意力，后接该分支专属的瓶颈 Adapter。 |
| 时间适配 | 交换相位轴与空间块索引，在固定位置的相位序列上做多头自注意力，经专属 Adapter 和分支残差后，换回原布局。两支共享预训练的注意力与相应 LayerNorm 权重。 |
| 融合 | 对齐后按元素相加，经过 LayerNorm、原预训练 MLP 及与 MLP 并联的第三个 Adapter，沿用图 2 的残差连接。三个 Adapter 均采用降维、ReLU、升维的瓶颈结构。 |
| 训练 | 各策略都训练启用的 Adapter 和两端通道映射，块内 SAM 预训练权重全程固定。RSTAR 编码器、解码器和输出层按所选策略从首步参与更新、全程冻结或在预热后解冻。 |

STAM 图 1 在多个深度重复 Joint Block，并另设全相位先验编码器和解码器。本次迁移的边界是图 2 的单块。RSTAR 本身已输入同次扫描的静态先验，继续用它的原版编码、跳跃连接和图像输出。

## 2. 输入、输出与计算契约

接入点为 Stage II 的 $\mathrm{conv4\_3}(\mathrm{conv4\_2}(x_3))+x_3$ 之后、第一次上采样 $\mathrm{conv5}$ 之前。瓶颈特征布局为 $[B,128,T,Z',Y',X']$。把每个 $z'$ 作为独立组，平面块数为 $N=Y'X'$。对每组分别运行 $T\times N\times D$ 的 Joint Block，最后恢复三维布局。上游特征已经包含层间上下文，后续解码继续利用 RSTAR 的 Z 向卷积。[Stage II 前向](../../../rstar4d/models/official_stage2.py)

为复用公开的 SAM 权重，首轮建议选用 **SAM ViT-B 的一个预训练全局注意力块**，可预先固定为从 0 开始计数的第 5 块。其宽度为 768，采用 12 个注意力头。外部用逐位置线性层将 128 通道映射为 768，再将单块输出映射回 128 通道，与原瓶颈残差相加。输出映射权重和偏置从零开始，初始函数因此等于同一权重的原版 RSTAR。ViT-B、层号、插入位置都是此次移植的选择；STAM 正文未指定所用 SAM 变体或相应的单块层号。[SAM 官方配置](https://github.com/facebookresearch/segment-anything/blob/main/segment_anything/build_sam.py)

首轮可将三个 Adapter 的中间宽度统一设为 64。空间分支用实际 $Y'\times X'$ 网格计算注意力；STAM 正文未交代时间分支如何处理 SAM 的二维相对位置项，本方案将时间序列排为 $T\times1$ 网格，复用同一注意力层及官方相对位置插值函数。这一选择保留权重共享，时间轴位置偏置继承的是空间预训练，其有效性仍需在实际心动序列上检验。图 2 的块拓扑与冻结策略属于文献依据，以上尺寸和位置处理属于本次适配。[SAM 官方注意力实现](https://github.com/facebookresearch/segment-anything/blob/main/segment_anything/modeling/image_encoder.py)

### 2.1 数据边界

| 位置 | 张量布局与约束 |
|---|---|
| 模型入口 | $[B,2,T,Z,Y,X]$。第一通道为按相位排序的稀疏 FDK，第二通道为同一次扫描的静态先验沿时间复制。沿用基线的物理坐标、相位顺序、强度校准和先验构造方式。 |
| 瓶颈 $F$ | 对对齐到步幅的输入，尺寸为 $[B,128,T,Z/2,Y/8,X/8]$。若输入空间尺寸为奇数，先由现有 forward_volume 做填充，输出按原尺寸裁回。 |
| 平面注意力 | 每个样本、每一粗尺度轴向层、每个相位是一组。组数为 $BZ'T$，每组有 $Y'X'$ 个位置。 |
| 时间注意力 | 每个样本、每一层、每个平面位置是一组。组数为 $BZ'Y'X'$，每组有 $T$ 个位置。所有空间裁块保留该样本的实际相位，覆盖项目中的 $T=10,11$。 |
| 预测出口 | $[B,1,T,Z,Y,X]$，继承原输入相位顺序和网格。训练使用同相位全视角参考及有效域，推理只读取分相 FDK 和静态先验。 |

### 2.2 残差和参数共享

以下为本项目对图 2 的逐步实现约定，区分 Adapter 内部残差、分支残差和接回 RSTAR 的外部残差。令 $U=P_\mathrm{in}(F)$ 为逐位置的 768 维特征；$R$ 表示将每个空间位置的特征排成时间序列，$R^{-1}$ 恢复布局。每个 Adapter 定义为 $A_i(h)=h+W_{i,u}\operatorname{ReLU}(W_{i,d}h+b_{i,d})+b_{i,u}$。三组 Adapter 参数独立。$M$ 是同一份冻结的 SAM 注意力，包括 QKV、输出映射和相对位置表。$L_1,L_2$ 是预训练块中两个不同的 LayerNorm。

$$
\begin{aligned}
S &= U+A_s(M_{\rm XY}(L_1(U))),\\
H &= R^{-1}\!\left(R(U)+A_t(M_{\rm T}(L_1(R(U))))\right),\\
G &= S+H,\qquad h=L_2(G),\\
J &= G+\mathrm{MLP}(h)+A_f(h),\\
F' &= F+P_\mathrm{out}(J).
\end{aligned}
$$

XY 与 T 表示同一注意力参数在两种网格布局上的调用，同一个 $L_1$ 参数对象用于两支。$F'$ 还原为原瓶颈布局交给 conv5。仅时间消融将 $S$ 设为恒等跳连 $U$，旁路空间注意力和空间 Adapter；这保留了相加处的恒等项，使两个实验组的区别集中在学习的空间特征上。关闭模块时直接将 $F$ 传给 conv5。主方案不带早期草案中的跨相位值差分。

新建模型时从 SAM 的 image_encoder.blocks.5 严格提取 norm1、attn、norm2、mlp 权重，记录来源与文件 SHA-256，核对相对位置表、12 个头和 768 维宽度。只实例化这一块。P_in 和 Adapter 使用可复现的线性层初始化；P_out 的权重及偏置均为零。相同种子下按照参数名或独立随机数流初始化共用的新层，防止消融组因少一个 Adapter 而改变时间分支初值。

## 3. 冻结训练与联合微调

起点选在同一训练划分、同一预处理下已经训练好的猪心原版 **Stage II** 基线，先复现其验证结果。若手头只有公开胸部权重，先评估它在猪心上的基线误差。直接从胸部权重冻结训练时，所检验的是跨域适配；要回答既有猪心基线还能涨多少，须使用该基线自己的权重。加载完整 Stage II 权重时走严格加载路径。项目的 Stage I→II 初始化会重置 Z 向卷积，适用于由 Stage I 开始训练 Stage II。[模型初始化](../../../rstar4d/models/model.py)

**全程冻结（`frozen`）。** 从第一个优化步到最后一步均固定 RSTAR 编码器、解码器和输出层。优化器只接收三个 Adapter 和两端通道映射，完整块共 494,912 个可训练参数。冻结参数使用 `requires_grad_(False)`，编码器输出可分离，解码器前向仍须保留对其输入的求导路径。对照训练前后的冻结权重及有状态缓冲区。[训练器的优化器构造](../../../rstar4d/training/trainer.py) · [PyTorch 自动求导](https://docs.pytorch.org/docs/main/notes/autograd.html#setting-requires-grad)

**直接联合（`joint`）。** 从同一原版权重独立启动，在第一次前向之前启用 RSTAR 原参数的梯度，Adam 从第一步就包含主干和新增部分两个参数组。主干学习率默认取新增部分的十分之一。整条编码器—瓶颈—解码器路径保留梯度，不分离瓶颈或跳跃连接。零初始化的输出投影使初始预测等于原版；首个有效更新中，主干可沿原有残差路径更新，新增部分先更新输出投影，后续梯度再传到输入投影和 Adapter。

**预热后联合（`joint_after_warmup`，可选）。** 先按 frozen 更新新增部分，到预设 epoch 边界再启用主干参数组，保留已有 Adapter 的 Adam 状态和调度进度。同一运行可自动切换；需要验证预热效果时，还可以从同一预热检查点派生持续冻结与解冻两组。

### 3.1 首轮默认配方

以项目现有猪心 16 GB 配置为底稿。两种独立策略均按同一总预算从第 1 个 epoch 开始。10 个 epoch 的预热长度只用于第三种策略。预算或学习率如需根据验证集调整，在正式对照前锁定。[原版猪心配方](../../../configs/train/pig_local_16gb.yaml)

| 项目 | 默认配置 |
|---|---|
| 结构与输入 | 完整组为 joint，消融为 temporal_only，基线为 off。沿用来源 checkpoint 的 RSTAR profile 和相位拓扑。 |
| 优化与损失 | Adam，继承原版 betas、训练损失 public_code 和 SSIM 权重 0.1；猪心默认输入强度缩放为 0.02，offset 为 0。比较时与所用基线元数据一致。 |
| 预算 | 冻结和直接联合均独立训练 30 个 epoch。可选预热策略采用 10 个冻结 epoch 加 20 个联合 epoch。各组使用配对的批次、梯度累积与选模规则。 |
| 学习率 | 新增部分初始为 $1.5\times10^{-4}$，在第 10、20、25 个 epoch 结束后乘 0.5。直接联合从第 1 个 epoch 给主干 $1.5\times10^{-5}$，同步衰减。预热后联合在第 11 个 epoch 以 $7.5\times10^{-6}$ 启用主干。冻结策略始终只调度新增参数组。 |
| 采样与显存 | 空间块 ZYX 依次可取 $16\times128\times128$、$32\times96\times96$、$64\times64\times64$。同批次比较使用相同随机种子、有效域、增强和时间顺序。 |
| 选模 | 保留现有训练器按固定验证裁块的病例平均 L1 选 best.pt 的规则。同一实验阶段内比较合格检查点，持平取较早者。主研究终点另在整例、原强度域计算。 |

## 4. 对照实验与成功条件

**训练策略的主对照为 D 对 G**：同一猪心 Stage II 起点、同一完整 Joint Block 初始化、同种子、同批次、同新增模块学习率、同总训练预算及候选检查点范围，只改变 RSTAR 是否参与优化。G 对 H 进一步检验联合训练中新模块的增量。A/B/C 用于冻结条件下的结构消融；E/F 用于可选的预热研究。

| 组别 | 设置 | 可以回答的问题 |
|---|---|---|
| A | 训练完成的原版 RSTAR4D，直接评估 | 原版的局部重建质量及运动保真度 |
| B | RSTAR 冻结，仅时间分支训练 10 个 epoch | 与 C 比较时，测试学习的空间分支是否带来增量 |
| C | RSTAR 冻结，完整 Joint Block 训练 10 个 epoch | C 对 A 检验完整模块的独立收益，C 对 B 检验空间分支及其 Adapter 的增量 |
| D | 从 A 独立启动，完整块采用 frozen 全程训练 30 个 epoch，可在第 10 个 epoch 同时取得 C 的结果 | D 对 G 比较全程冻结与从首步联合 |
| E | 完整块采用 joint_after_warmup，从第 11 个 epoch 联合训练，前 10 个 epoch 与 D 配对 | E 对 D 比较预热后的解冻效果；E 对 G 检验冻结预热的作用 |
| F | 从 A 权重启动，无新模块，以 E 的主干学习率运行第 11–30 个 epoch 的相同数据流 | F 对 A 量化额外主干训练本身的收益；E 对 F 比较在主干更新预算相同时，包含完整模块的训练方案是否更好 |
| G | 从 A 独立启动，完整块采用 joint，从第一个优化步联合训练 30 个 epoch | 与 D 使用同一完整模型，测试从首步更新 RSTAR 的收益 |
| H | 从 A 独立启动，原版 RSTAR 按 G 的主干学习率和相同批次继续训练 30 个 epoch | G 对 H 检验在相同主干更新预算下加入完整模块的收益 |

B 是从 C 中删去空间分支所得的匹配对照，旧方案中的差分注意力有不同的融合公式和权重来源，不能替代这个对照。C 对 B 衡量整条空间分支的净收益，其中也包含新增 Adapter 容量。若需单独归因于 SAM 预训练，再增加一次同结构、同冻结规则的随机初始化对照。

猪心配对数据上，主要指标为可信左室轮廓内外各两个体素的边界带 MAE，以同相位全视角图像为参考，按动物配对汇总。同时报告全有效域 MAE、固定窗 SSIM，以及有标注动物的舒张末至收缩末左室容积变化误差。完整模块优于原版且保住运动幅度，支持本次移植；完整模块同时优于 B，才说明在这个宿主上新增空间分支值得。STAM 表 4 的模拟患者 MAE 22.85 HU 与去除时间分支后的 25.35 HU，反映的是 STAM 内部对照，不能据此预测 RSTAR 的数值增益。

**指标口径。** 在原重建网格的体素索引空间，以三维欧氏距离分别选取 LV 内侧距最近背景体素中心不超过 2 的前景体素、外侧距最近前景体素中心不超过 2 的背景体素，二者并集与有效 FOV 相交。按相位编号关联可信标注与图像，缺标相位不计入边界指标；覆盖率按动物、扫描、相位列出。边界带 MAE 单位为 $\mathrm{mm}^{-1}$，每个相位内先平均体素，再依次平均同一扫描内可评价相位、同一动物内扫描、不同动物。全有效域 SSIM 使用既有 $[0,0.05]$ 固定窗和 $11\times11$ 局部窗口。[原版评估实现](../../../rstar4d/evaluation/image_metrics.py)

在有可信 ED、ES 相位标签的扫描上，用同一冻结轮廓提取器测量各模型预测的 LV 容积，按真实体素间距换算 mL，比较 $\lvert(\hat V_\mathrm{ED}-\hat V_\mathrm{ES})-(V_\mathrm{ED}-V_\mathrm{ES})\rvert$。预设相位编号不能代替生理标签。提取失败须报告空轮廓数及原因；缺少成对参考时，保留可评价的逐相位结果，运动幅度结论记为待验证。

**判定与报告。** 以动物划分训练、验证、留出测试集。预实验用种子 2026，正式对照建议配对使用 2026、2027、2028。验证结束后锁定配方、运动非劣容许量及来源（有重复勾画时优先采用测量重复性；缺少可靠估计时，默认要求平均幅度误差不增加），在留出集统一评估。报告按动物配对的 MAE 差、获益动物数及动物级重采样区间。多种子先在同一动物内汇总，避免把种子或相位当作独立动物。平均边界 MAE 下降且运动指标达到上述条件，才将该方案列为性能候选；区间跨零时报告为方向性结果。分别报告 G 对 D 的动物级差异和 G 对 H 的净收益。若直接联合相对冻结的改善处于训练波动内，优先保留 D；可选预热策略也按相同标准比较。若没有足够可信边界标注，记录主终点不可判定，另报全图效果。

完整模块在每个粗尺度层面还要计算平面注意力，其得分矩阵每头、每相位为 $N\times N$，另有逐位置的 $T\times T$ 时间注意力。训练前用项目的三种实际裁块分别测冻结期和联合期的峰值显存及反向传播开销，并测推理时间。可沿独立的 $z'$ 分组计算并使用梯度检查点。空间滑窗会改变平面可见范围，因此各组使用同一裁块和滑窗协议，并检查共享中心区域的一致性。设计阶段尚无训练结果。[本地训练配置](../../../configs/train/pig_local_16gb.yaml) · [推理窗口实现](../../../rstar4d/inference/sliding_window.py)

## 5. 配置、运行入口和检查点

下列接口为实现目标。在既有严格 YAML 配置中添加可选 stam 小节，以 mode 为架构开关、train_policy 为训练策略。架构与训练策略分别保存，推理仅按架构装配模型。

| 配置字段 | 取值与行为 |
|---|---|
| stam.mode | off 为默认值；temporal_only、joint 仅对 Stage II 有效。原版 Stage I、旧配置和旧权重走既有入口。 |
| stam.train_policy | 对 joint 和 temporal_only 两种架构均可独立选择 frozen、joint 或 joint_after_warmup。启用模块而未指定策略时默认 frozen。架构 off 沿用原版训练，供 F、H 配置匹配的主干学习率及预算。 |
| stam.sam_checkpoint | 新建启用模块的运行时提供本地 SAM ViT-B 权重路径，解析并记录校验和。启用时如块的类型、键集或尺寸不匹配，在训练开始前报告具体字段。 |
| stam.warmup_epochs / stam.backbone_lr_ratio | 只有 joint_after_warmup 读取预热长度，默认 10，范围为 1 至总 epoch 数减 1。frozen 和 joint 的有效预热长度均为 0。主干参与训练时学习率比例默认 0.1，须为正数；frozen 的优化器中没有主干组。 |
| 其余结构常量 | v1 固定 block_index=5、embed_dim=768、num_heads=12、adapter_dim=64、temporal_grid=T×1、单次瓶颈接入。解析后的完整结构写入 checkpoint。 |

**配置示例。** 在同一份 Stage II 配置的 `stam` 小节中，保留相同 SAM 路径，以下两份片段只改一行即可分别独立启动。

```yaml
# 全程冻结 RSTAR
stam:
  mode: joint
  train_policy: frozen
  sam_checkpoint: /path/to/sam_vit_b.pth
```

```yaml
# 从首步联合训练 RSTAR 和新增部分
stam:
  mode: joint
  train_policy: joint
  sam_checkpoint: /path/to/sam_vit_b.pth
```

这两种运行在各自的新目录中使用 `--init-from-stage2` 加载同一个原版 checkpoint。预热检查点和 `--fork-from` 仅用于需要复用共同训练前缀的对照实验。

**训练初始化。** 通过原版 train 的 Stage II 初始化入口严格加载完整 RSTAR，再装配并加载新块。按原 checkpoint 的 model_profile、强度域、归一化和数据划分验证兼容性，保留来源权重哈希。裸权重需配套明确这些元数据。原先的 Stage I→II pipeline 保留其原版行为；请求启用此实验时，入口应指向已经训练好的 Stage II 权重。配置校验、模型工厂、训练器与推理器共用同一架构描述。[配置校验](../../../rstar4d/config.py) · [命令行入口](../../../rstar4d/cli.py) · [模型工厂](../../../rstar4d/models/model.py)

**实验分支与中断恢复。** 为 train 引入计划接口 --fork-from，仅在新实验目录从预热结束的完整训练检查点派生，与 --resume、--init-from-stage2 等初始化方式互斥。选择复用前缀时，在第 10 个 epoch 边界保留 C 的 last.pt，分别派生冻结、预热后联合的配对运行，并记录父文件 SHA-256。独立启动的 D、G 各自在原运行目录连续训练。派生时复制模型、已有 Adapter 的 Adam 状态、调度器进度、AMP scaler、RNG、采样种子、验证样本及绝对 epoch/step。只允许实验注册的冻结策略和运行身份发生变化，数据快照、主干、模块配置均需匹配。E 在首次解冻时只给 RSTAR 建一次新的 Adam 状态；D 和 E 的 Adapter 学习率从同一进度继续。F 从 A 权重新建主干优化器，以相同绝对 epoch 和种子读取第 11–30 个 epoch 的裁块。记录实际成功更新和溢出跳步，若配对的有效预算不匹配，在结果中标出并在正式比较前复核。

同一分支内部的 --resume 仍按原版在已完成 epoch 边界恢复，核验目录身份、签名和历史 best。明示保存结构版本、train_policy、当前冻结状态、参数组名称与顺序、父检查点哈希；恢复时先装配对应参数组，再加载优化器和调度器状态。独立启动的 D、G 在相同的第 1–30 个 epoch 选模，比较 D、E、G 时共用这一范围。派生 D、E 时将冻结前缀的历史 best 复制为两组共同的早期候选，并从同一 last.pt 继续训练；验证预热结束后的增量时单列第 30 个 epoch 的固定终点。F、H 将 A 作为初始候选。各自历史保存在各自运行目录。[原版训练器](../../../rstar4d/training/trainer.py) · [检查点读写](../../../rstar4d/training/checkpoint.py)

**推理与可追溯性。** 新 checkpoint 包含被冻结 SAM 块的权重、全部新增层以及 RSTAR 状态。infer 根据元数据重建模型并严格加载，部署机器无需访问训练时使用的独立 SAM 文件。旧 checkpoint 缺少扩展字段时解析为 off。保持原有 full / tiled 输入、相位编号、强度尺度、padding 裁回和预测导出契约。正式比较锁定同一 tile/overlap；整例和空间滑窗的注意力视野不同，另报共享中心及接缝误差。每个结果关联结构模式、权重哈希、动物划分和推理设置。[推理入口](../../../rstar4d/inference/predict.py)

## 6. 实现验收清单

| 项目 | 操作和通过条件 |
|---|---|
| 原版兼容与初始等价 | 同一 Stage II checkpoint、同一输入、确定性 FP32 下，原版与 off 输出一致；joint 和 temporal_only 在 P_out 为零时也复现该输出。验证加载后的原版 Z 向参数逐项相等。 |
| 两种策略独立启动 | 使用同一 Stage II 原版 checkpoint、相同 SAM 权重、相同随机种子和两个空运行目录，分别以 frozen、joint 启动，不提供预热检查点。两组初始预测一致，解析出的策略、可训练参数及优化器参数组符合配置。 |
| 参数与梯度 | 用非均匀合成目标完成有效优化步。frozen 下完整块可训练参数为 494,912，temporal_only 为 395,776；训练前后 RSTAR 逐项相等，新增输出投影更新。直接 joint 下第一步同时检测到 RSTAR 参数和新增输出投影发生更新。两种策略下均验证 SAM 原权重逐项相等，首次更新之后梯度可到达输入映射和启用的 Adapter。 |
| 轴与布局 | 对模块本身用 $B=2,T=10/11,Z'>1$ 和非方形平面做分组参考实现对照。逐样本、逐层的循环输出与批处理输出在 FP32 下 allclose（rtol $10^{-5}$、atol $10^{-6}$）；改变一个样本的一层不影响模块输入中其他样本或其他层的输出。整网另测单样本、奇数空间尺寸和原尺寸裁回。 |
| 资源与数值 | 本地三种裁块均完成一次有效反传，记录可用显存、峰值分配和成功更新耗时。正式推理测每例时间，输出和梯度有限。必要时在相同空间窗口内沿独立粗层分块并做激活检查点；缩小空间窗口会改变实验条件，应同步到各对照。 |
| 派生与续训 | 分别中断和恢复独立的 frozen、joint 运行，核对可训练参数范围、Adam 参数组及下次更新。用配对的 D、E 检查预热边界前的预测和 Adam 动量一致，E 只在解冻时新增一次主干组。固定种子的确定性小样本上，各策略恢复与连续运行的权重、步数和学习率序列一致。 |
| 推理与评估 | 对旧 checkpoint、扩展 checkpoint 各跑一次实际 infer。扩展权重移至单独目录后能离线重载。核对有标注相位、缺标相位、空 ROI 和缺失 ED/ES 的指标分母与原因码；整例导出相位顺序、仿射与强度单位正确。 |

技术验收与效果判断分别记录。实施交付包括原版训练和推理入口支持、可复现实验配置、匹配上述行为的测试、动物级结果表和显存/耗时记录。开始正式实验前需要落实猪心原版 Stage II 检查点、SAM ViT-B 权重、锁定的数据划分和可信相位标注。本 Spec 交付时尚未执行模型训练或测得性能收益。
