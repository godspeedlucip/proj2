# 原版 RSTAR4D 接入 STAM Joint Block 实施计划

依据 [Spec v1.1](../specs/2026-11-25-rstar4d-stam-joint-block-design.md)。目标是在原版 Stage II 中插入一个完整 Joint Block，让同一份猪心 RSTAR 权重独立启动全程冻结和首步联合两种训练。两种策略共用同一网络、数据和推理入口。以下复选框供实施时记录进度。

**第一个可用版本**完成任务 1–4。届时可以用两个配置独立训练、断点续训、保存模型并离线推理。第 5 项补齐可选预热策略。第 6 项完成正式实验所需的测量，第 7 项比较训练效果。

## 1. 固定基线，打通配置入口

- [ ] 在项目根目录使用现有测试夹具，先运行模型、训练与推理回归，记录原版 Stage II 在确定性 FP32 输入上的输出。登记目标域 Stage II 检查点、模型 profile、强度校准、归一化、训练划分和 SAM ViT-B 权重的来源及哈希。真实权重与标注可在开发期间准备，早期接口测试使用项目的小体模和受控块权重。
- [x] 扩展严格配置校验，分别解析架构 `stam.mode` 与训练策略 `stam.train_policy`。新增两份猪心配置 `configs/train/pig_stam_frozen.yaml` 和 `configs/train/pig_stam_joint.yaml`，相同的完整块配置仅切换训练策略。模块默认关闭。检查 Stage I 误用、SAM 键或形状不匹配、联合训练学习率比例非法等输入。
- [x] **验收**：旧配置可以按原入口构建模型。两个新配置均能从同一原版 Stage II 检查点解析为有效预热长度 0，并得到相同的架构和初始化描述。[配置解析](../../../rstar4d/config.py) · [模型工厂](../../../rstar4d/models/model.py) · [猪心基础配方](../../../configs/train/pig_local_16gb.yaml)

## 2. 实现完整块并接入一个位置

- [x] 新建 `rstar4d/models/stam.py`，按 Spec §2.2 实现空间、时间分支、三个独立 Adapter 及融合端 MLP。两支共享同一对象的首个 LayerNorm 和注意力参数。复用 SAM 官方 ViT-B 块所需的运算，登记使用的源码版本及许可证；原版 off 路径可在原有依赖环境运行。启用时从第 5 块严格载入权重，部署时可以从扩展检查点直接构造。
- [x] 在 Stage II 的 `conv4_3` 残差相加后、`conv5` 上采样前接入一次。通道走 128→768→128，输出投影零初始化。先严格加载原版主干再装配新层，保留原参数名和已训练的 Z 向卷积。仅时间消融按 Spec 将空间输出设为恒等跳连。
- [x] **验收**：相同输入下 off、零初始化的完整块和零初始化的仅时间块均复现原版。另用**非零输出投影**对照逐层、逐位置循环实现，覆盖批量 2、10/11 相位、多个 Z 层及非方形平面，才能发现 XY、Z、T 换轴错误。验证完整块与仅时间块新增可训练参数分别为 494,912 和 395,776。[Stage II 前向](../../../rstar4d/models/official_stage2.py) · [既有模型测试](../../../tests/test_model.py)

## 3. 让冻结和联合从第一步独立工作

| 策略 | 第一次前向前的装配 | 首个有效优化步的判据 |
|---|---|---|
| `frozen` | RSTAR 与 SAM 预训练层固定。Adam 仅接收 Adapter 和通道映射；冻结的解码器仍对瓶颈输入求导。 | 新增输出投影改变，原版主干参数逐项相等。 |
| `joint` | 从同一原版 Stage II 和相同新增层初值启动，RSTAR 与新增部分分别进入 Adam 两个参数组。SAM 预训练层仍固定。 | 主干和新增输出投影均改变，SAM 权重逐项相等。 |

- [x] 在训练器构造优化器之前应用策略，用稳定的参数组名称记录主干和新增部分的学习率。联合训练首轮默认值分别为 $1.5\times10^{-5}$ 和 $1.5\times10^{-4}$，随同一组里程碑衰减。检查参数组无重复、冻结参数未进入优化器。
- [x] 用同一非均匀小体模连续执行至少两次有效更新。零初始化意味着新分支首步梯度先到输出投影，再验证后续梯度到达输入投影和启用的 Adapter。检查每轮 `model.train()` 后的冻结状态、损失和有限梯度；AMP 溢出跳步单独计数。
- [x] **验收**：用两个空运行目录分别执行下列命令。两个运行均从原版权重直接启动，初始输出一致，更新行为满足上表。命令用于实现后的短程检查；配置路径为本计划第 1 项交付，PowerShell 变量指向同一份已核对的数据与权重。

```powershell
python -m rstar4d train --stage 2 --config configs/train/pig_stam_frozen.yaml --manifest $manifest --split $split --init-from-stage2 $stage2Weights --run-dir $frozenRun --stop-after-epoch 1
python -m rstar4d train --stage 2 --config configs/train/pig_stam_joint.yaml --manifest $manifest --split $split --init-from-stage2 $stage2Weights --run-dir $jointRun --stop-after-epoch 1
```

主要代码位置见[训练器](../../../rstar4d/training/trainer.py)、[损失函数](../../../rstar4d/training/losses.py)和[命令行入口](../../../rstar4d/cli.py)。

## 4. 完成断点续训和离线推理

- [x] 写入结构版本、策略、源权重哈希、冻结状态、参数组名称与顺序，以及全部模型权重。沿用现有优化器、调度器、scaler、RNG、绝对 epoch/step、历史 best 和数据签名机制。恢复时先按策略构建相同参数组，再加载状态。
- [x] 让 train、infer、benchmark 通过同一模型装配逻辑构造扩展模型。推理按模型结构加载，旧检查点缺少扩展字段时走 off。扩展检查点携带所需 SAM 块权重，应用环境可离线加载。保留 full/tiled、相位索引、强度反归一化及空间裁回。
- [x] **验收**：两种独立策略分别在 epoch 边界中断和恢复，与相同种子下连续训练比较步数、参数和学习率序列。移开独立 SAM 权重文件后，用实际 infer 入口加载扩展检查点。测试旧权重推理、奇数尺寸、10/11 相位。在同一推理模式下核对保存前后输出。[检查点](../../../rstar4d/training/checkpoint.py) · [推理入口](../../../rstar4d/inference/predict.py) · [空间滑窗](../../../rstar4d/inference/sliding_window.py)

## 5. 添加可选预热及实验派生

- [x] 实现 `joint_after_warmup`。默认第 10 个 epoch 结束时保留可复用的冻结检查点，从第 11 个 epoch 起只增加一次主干参数组。保留已有 Adam 动量和调度进度，此时新增部分、主干学习率分别为 $7.5\times10^{-5}$、$7.5\times10^{-6}$。
- [x] 实现 Spec 的 `--fork-from`。从同一父 last 派生两个新运行，复制前缀历史 best 并记录父哈希。派生运行保留绝对 epoch、裁块序列和验证样本；同一运行内部的恢复沿用 `--resume`。按原版继续训练的 F 对照从第 11 个绝对 epoch 读取对应批次和学习率。
- [x] **验收**：以缩短的冻结期做确定性测试，核对解冻前、解冻后两个边界的恢复结果。另测源/目标模式不匹配和错误的父数据快照。两种首步独立策略的启动链路继续通过第 3 项测试。

## 6. 接通评估，测量资源

- [x] 在现有评估入口按实际相位标签关联可信 LV 标注，生成内外各两个体素的边界带并与有效 FOV 相交。复用原强度域 MAE 和固定窗口 SSIM。用体素间距及同一冻结轮廓提取器计算有可信 ED/ES 标注扫描的容积变化误差。缺标、空 ROI、提取失败分别计数。用解析形状的小体模核对边界选择、mL 换算和动物等权汇总。[图像指标](../../../rstar4d/evaluation/image_metrics.py) · [评估报告](../../../rstar4d/evaluation/report.py)
- [x] 修改现有 benchmark 的更新检查。它目前检查第一层卷积权重是否变化，正确冻结的模型也会被判失败。按第 3 项的策略判据检查，使用训练器相同的模型和参数组。对 $16\times128\times128$、$32\times96\times96$、$64\times64\times64$ 三种 ZYX 裁块分别在冻结和联合模式做有效反传，记录参数量、峰值显存和耗时。遇到显存不足优先按独立 Z 层分块或做激活检查点，再复核中心区域与未分块参考的一致性。
- [ ] **验收**：真实权重的小规模验证病例可从训练输出走完 infer→evaluate。对相同滑窗协议报告有标注相位的边界 MAE、有效样本数及每例耗时；另测 full 与 tiled 视野变化引起的中心/接缝差异。锁定 GPU 可运行的配置及有效更新预算，再进入长训。

## 7. 按实验问题安排运行

| 顺序 | 组别与预算 | 作出什么判断 |
|---|---|---|
| 先复现 | A 为已有猪心原版 Stage II，复现固定验证样本及整例预测 | 确认权重、强度单位、推理窗口和动物划分一致。 |
| 首轮主对照 | D 全程冻结 30 个 epoch；G 从首步联合 30 个 epoch；H 原版按 G 的主干学习率继续训练 30 个 epoch | D 对 G 选择训练策略；G 对 H 估计联合训练时新增模块的收益。三组匹配裁块、训练预算与选模规则。 |
| 结构消融 | D 训练到第 10 个 epoch 时保存该前缀的 last 和历史 best，复用为 C；B 仅时间分支冻结训练 10 个 epoch | C 对 A 检验冻结主干时完整模块的收益；C 对 B 检验空间分支的增量。 |
| 可选预热 | E 从 C 的 last 开始联合训练 20 个 epoch；F 从 A 按 E 的主干学习率和第 11–30 个 epoch 的样本流继续训练 | E 对 D 检验预热后解冻的价值，E 对 G 检验预热本身；F 对 A 量化相同主干更新预算的贡献。 |

首轮用种子 2026。正式比较按 Spec 配对使用 2026、2027、2028，在验证集锁定配方、候选检查点范围和运动容许量后统一评估留出动物。结果按扫描内相位、动物内扫描、动物间等权汇总，报告配对差、获益动物数和动物级区间。最终判断同时看左室边界 MAE 和舒张末至收缩末的容积变化误差，运动数据不足时单列不可判定。

**完成条件。** 工程交付为两种可独立启动的配置、可恢复训练、可离线推理、通过的策略测试和 GPU 资源记录。科研交付为与 Spec 分组对应的动物级结果及结论。实施时优先扩展现有 unittest，用 `python -m unittest tests.test_model tests.test_training tests.test_inference tests.test_cli` 检查主链路，再用 `python -m unittest discover -s tests` 执行项目回归。任务 1–6 的工程实现已落地。已完成本地 GPU 更新、体模 CLI 主链路和单例公开权重跨域检查。目标 RTX A6000 的实机测量、猪心原版 Stage II 与正式数据的溯源验收、A–H 动物级比较仍待执行。见 [训练与验收记录](../../stam-training.md)。
