# RSTAR-STAM 加入完整 3D DeCNN 的实施计划

2026-11-26 · 工程验收通过，正式动物实验待补齐 · 默认冻结已训练的猪心 Stage II RSTAR-STAM。[对应设计规格](../specs/2026-11-25-rstar-decnn-frozen-backbone-design.md)

[实施与验收记录](../../implementation-validation.md)汇总了四条训练配方、合成标定、GPU 测量和真实先验准备。涉及正式权重与动物级效应的条目保留待验证状态。

首轮要验证的是，**同一个 RSTAR-STAM 检查点，加上 DeCNN 以后，能否更准确地恢复左室边缘，同时保留舒张末到收缩末的容积变化。** STAM 已在瓶颈联合处理空间与时间特征。DeCNN 要补充的是另一条信息路径。它从当前相位的原始门控 FDK 和同次扫描的全投影 FDK 分别提取三维特征，在四个解码尺度上重新利用两幅图。它可能帮助恢复条纹附近的心壁，也可能把快速运动的边缘拉向平均位置。实验同时测这两种效应。

| 交付顺序 | 内容 | 完成标志 |
|---|---|---|
| 第一批 · 任务 1–4 | 复现现有主干，准备两路先验，实现完整 DeCNN，打通冻结训练、预测和离线融合 | 对同一例扫描，融合系数为 0、1 时可分别复现两支输出，主干在训练前后逐张量相等 |
| 第二批 · 任务 5 | 用冻结预测完成验证集标定与配对消融 | 得到相同动物上的四组结果、DeCNN 单支结果与运动误差，能够判断首轮是否值得采用组合 |
| 第三批 · 任务 6–7 | 支持直接从零、Tetris 分阶段、先冻结后解冻，验收梯度、续训与资源开销 | 四种训练路线各有可复现配置，可从检查点独立推理并在正确阶段续训 |

任务 5 的评价代码在冻结路线打通后即可开发。任务 6–7 的工程实现不依赖首轮是否观察到增益。计划涵盖四条训练路线，优先把正式训练预算用于默认冻结对照。

## 任务 2　建立两路先验与强度域的数据合同

在 `rstar_decnn/data.py` 从同一扫描组装以下样本。先按动物划分训练、验证和留出集，再从所属扫描取相位及空间块。

| 字段 | 构造与使用 |
|---|---|
| `X [B,1,T,Z,H,W]`、`Y`、`valid_mask` | 保留真实相位标签、方向、原点和体素间距。`Y` 与 `X` 同网格、同相位。训练和评价只使用有效域。 |
| `A_S [B,1,Z,H,W]` | 按主干检查点对应的训练快照读取先验。猪心数据常用 `phase_weighted_fdk`。沿时间展开，与 `X` 在通道轴拼接，向原主干提供 `[B,2,T,Z,H,W]`。 |
| `A_D [B,1,Z,H,W]` | 使用同次动态扫描所有混合投影做一次 `all_views_fdk`。如已保存相同来源和校准的全投影先验，直接复用。DeCNN 每次只读 `X[:,:,t]` 与 `A_D`，两者各为一个三维体积。 |

- [x] 保留原扫描文件。在现有 `prior` 只有 `A_S` 时，读取 `projections.h5` 内的 `mixed_line_integral`、角度和对应几何，按原重建与校准顺序生成 `A_D`，单独保存并由清单关联。检查扫描标识、输入摘要、先验模式、网格与校准。原投影缺失时，查找可追溯的同次扫描仿真输入以复现混合投影，并核对门控重建。只能取得既有先验的病例须单列为共用先验实验。[猪心先验生成与投影存储](../../../../RSTAR-STAM/rstar4d/simulation/pipeline.py)
- [x] 对 `X_t、A_S、A_D、Y_t` 和掩膜使用相同的空间裁剪与增强。分别应用主干检查点的归一化和 DeCNN 固定可逆的线性变换 `g`。后者用采集协议或训练动物校准，使有效监督范围可由 ReLU 表示。保存尺度、偏移、单位及超界计数，避免裁掉负值后再声称可以逆变换。
- [x] **验收时**，用相位标签乱序、物理网格偏移、先验来源缺失和含负值的校准样本覆盖数据入口。标签可配对时按标签对齐，网格或来源不匹配时给出病例级错误。验证两种变换各自往返以及裁剪后同一地标的位置。验证、留出和无参考推理均可仅凭输入生成两路先验。

## 任务 3　按原论文实现完整 DeCNN

- [x] 在 `rstar_decnn/decnn.py` 实现单相位接口 `DeCNN3D.forward(gated, prior) -> enhanced`。两路输入和输出均为 `[N,1,Z,H,W]`。两套独立编码器的四级跳连宽度为 32、64、128、256，各自到达 512 通道，在瓶颈拼接为 1024 通道。保留三维卷积、BN、ReLU、四次最大池化及图 1 深层的 0.5 dropout。
- [x] 解码四次，每次上采样后同时拼入两个编码器的同尺度特征。末端 `1×1×1` 卷积加 ReLU，直接输出同相增强体图。按图 1 核对卷积顺序、层宽和跳连。对论文未指定的上采样细节在配置中固定。每个相位复用同一套 DeCNN 参数。输出端的标量融合属于本项目的接法。原文比较过单编码器 CNN，移植后的增益由任务 5 单独检验。[DeCNN 原文图 1 及实验](https://pmc.ncbi.nlm.nih.gov/articles/PMC8979258/)
- [x] 训练使用真实连续的三维块，推理对 `Z,H,W` 分别补至 16 的倍数，完成解码后裁回原网格。主干沿用原 profile 的补边与相位拓扑。小体块训练样例需保证 BN 在最深层有足够样本元素。
- [x] **验收时**，检查两编码器参数存储独立，四级解码器各收到两路跳连，奇数空间尺寸可恢复。固定 `X_t` 和 `A_D`、改动其他相位，在评估模式下该相输出应相同。使用非均匀输入和有效目标反传，确认两编码器和解码器各有参数获得梯度。此路径不需要三个重叠时间窗。

## 任务 4　打通默认冻结训练、在线预测与离线融合

- [x] 在 `rstar_decnn/train.py` 实现 `frozen` 配方。将**整个**已训练的 RSTAR-STAM 设为 `eval()`、关闭梯度并排除在优化器外，覆盖 RSTAR、SAM、三个 Adapter、输入和输出映射。组合模型切回训练模式时须维持冻结主干的评估状态。原有 `stam.train_policy=frozen` 仍训练 Adapter 和映射，不能直接用于此配方。[STAM 实现](../../../../RSTAR-STAM/rstar4d/models/stam.py)
- [x] 在训练动物上，仅用有效体素计算 DeCNN 输出与 `g(Y_t)` 的同相位 MSE。独立选取 DeCNN 检查点，事先固定选模规则，如验证动物等权的三维 MSE 最低。此时无需逐步计算主干。保存普通 RSTAR、完整 RSTAR-STAM、同一 DeCNN 的物理域预测，分别记作 `R`、`S`、`D*`。其中 `D* = g⁻¹(D)`。
- [x] 在 `rstar_decnn/predict.py` 实现唯一的融合函数 `(1−α)S + αD*`，以及仅用于推理的端点旁路。`α` 是跨动物、相位与体素共用的标量。在线推理和离线标定调用同一函数。缓存按病例与相位标识索引，附权重、输入、校准、网格、滑窗与划分摘要。更换其中任一项时重新生成相应预测。
- [x] **验收时**，两次有效优化器更新前后逐张量比较主干参数及全部 buffers，要求完全相等，DeCNN 权重须有变化。确定性 FP32 下，`α=0` 复现任务 1 的 `S`，`α=1` 复现独立 `D*`。对 `α=0.35` 比较在线与缓存输出。建议在物理域用 `rtol=1e-5, atol=1e-7` 作首轮工程容差，输出最大差。端点测试要包含一例需要空间补边的序列。

## 任务 5　在验证集定系数，完成主消融

- [ ] 在 `rstar_decnn/evaluate.py` 复用原猪心的左室边界与容积评价。验证时对 `R` 和 `S` 分别搜索全局 `α_R` 和 `α_S`。首轮建议取 `0, 0.05, …, 1`，两支使用同一网格和同一批已冻结的 `D*`。各组合均相对于自身基线约束动物等权平均运动误差的增加量，在满足约束的候选中取边界 MAE 最小者，并列取较小系数。运动容许量在搜索前登记，有重复勾画时按测量重复性估计，否则采用 0 mL。各候选在同一批配对动物上比较，并报告轮廓提取失败，避免失败病例减少反而改善分数。对出现额外提取失败、无法与基线配对的候选，记录缺失并将其列为运动证据不足。[左室指标实现](../../../../RSTAR-STAM/rstar4d/evaluation/lv_metrics.py) · [既有 STAM 评价约定](../../../../RSTAR-STAM/docs/superpowers/specs/2026-11-25-rstar4d-stam-joint-block-design.md)
- [ ] 锁定数据划分、权重、轮廓提取器、融合系数、评价脚本与运动容许量后，统一评价留出动物。验证期间可反复使用验证预测。留出结果仅用于比较已锁定的方案。

| 结果行 | 预测 | 配对比较 |
|---|---|---|
| RSTAR | `R` | 原版基线 |
| RSTAR-STAM | `S` | 与训练起点及预算匹配的 RSTAR 比较 |
| RSTAR + DeCNN | `(1−α_R)R + α_R D*` | 相对 `R` 的增量 |
| **RSTAR-STAM + DeCNN** | `(1−α_S)S + α_S D*` | **相对 `S` 的增量，首要比较** |
| DeCNN | `D*` | 检查完整单支是否已能解释组合表现 |

- [ ] **主终点**取可信左室轮廓内外各两体素的边界带与有效 FOV 的交集，算物理域 MAE。**运动指标**取 `|(预测 ED 容积−预测 ES 容积)−(参考 ED 容积−参考 ES 容积)|`，以 mL 计，使用真实 ED/ES 标签、同一冻结轮廓提取器和真实体素间距。记录缺标、空边界、提取失败及各指标有效动物数。若缺足够 ED/ES 对，可输出边界探索结果，运动验收记为待验证。
- [ ] 先在扫描内汇总相位，再在动物内汇总扫描。预实验种子用 2026，正式对照配对使用 2026、2027、2028。多种子先在同一动物内汇总，再对动物级配对差重采样，报告区间和获益动物数。附全图 MAE、固定窗 SSIM、代表性快速运动相位剖面以及整序列资源开销。
- [ ] **判读结果。** 在留出动物上，组合相对 `S` 的平均边界 MAE 下降且运动误差满足容许量，才有理由保留该结果。区间跨零标为方向性结果。`α_S=0` 表示验证规则选中原主干，`α_S=1` 表示选中 DeCNN 单支。若专门分析 STAM 在融合后的作用，可增报两组共用一个 `α` 的结果，此时两幅融合预测之差恰为 `(1−α)(S−R)`。
- [ ] **机制消融按研究问题追加。** 要区分先验来源与网络结构的作用，先做 `A_D=A_S` 的同先验对照。要检验全投影图是否提供了额外信息，保持完整双编码器并将先验支改读 `X_t` 后重训。要检验独立编码的价值，用相同的 `X_t、A_D` 训练早期融合单编码器，匹配容量、训练预算、主干和标定规则。

## 任务 6　增加其余三条训练路线

在同一个模型与训练入口上设置下列配方。联合阶段计算融合图的原猪心任务损失，加 `λ × MSE(D,g(Y))`，`λ>0`。融合先在物理域计算，再将融合预测和参考转回任务损失约定的尺度。`α` 可从 0 起步，每次更新后投影到 `[0,1]`。联合训练从一开始计算两支前向，保证 `α=0` 时 DeCNN 仍从自身 MSE 获得梯度，`α` 也能收到任务损失梯度。

| 新配方 | 执行顺序 | 专项验收 |
|---|---|---|
| `scratch_stage2` | 直接构造 Stage II，随机初始化 RSTAR、STAM 所用 SAM、Adapter／映射和 DeCNN，显式开放 SAM 的梯度。使用完整相位序列和三维块训练。可另设“任务网络从零＋冻结预训练 SAM”的迁移对照，写明来源。 | 移除外部权重路径后仍能启动。STAM 输出映射按现实现为零初始化，待映射首次有效更新后，再验证 SAM、Adapter 的梯度与更新。同时核查主干和 DeCNN。 |
| `tetris` | Stage I 用 `Z=1`、多相位，仅训练普通 RSTAR。转段时先建普通 Stage II，调用 `initialize_stage2` 迁移 Stage I 权重并初始化新启用的 Z 卷积，随后 `attach_stam`，在真实连续三维块上接入 DeCNN。严格从零时随机 SAM 可训练。若预训 DeCNN，显式登记其独立三维训练来源。 | 比较转段前后的公共权重、Z 权重初始化与参数组，断言 Stage I 从未运行 STAM 或 DeCNN。完整 Stage II 检查点续训只做恢复，避免重复初始化 Z 层。 |
| `warmup_unfreeze` | 从任务 1 的已训练 `S` 开始，先整体冻结并训练 DeCNN。约定解冻步数，登记预热结束时的 `α`（可使用已锁定的验证标定值）。边界后开放 RSTAR、STAM Adapter／映射、DeCNN 与 `α`，原预训练 SAM 保持冻结。为新启用的组设学习率。 | 解冻前后两支预测和 `α` 连续。已训练分支保留 BN、优化器动量及调度进度，新启用参数只加组一次。解冻后检查主干、新层、DeCNN 的梯度及 SAM 的逐张量相等。 |

现有 `STAMJointBlock` 构造时会固定 SAM。仅在组合项目确切选择“随机 SAM、从零训练”的路线后显式开放其参数。不同训练策略的性能分别成表。若评价解冻的收益，应从同一预热末检查点派生“继续冻结”和“开始解冻”两组，匹配后续更新预算。[STAM 构造与参数初始化](../../../../RSTAR-STAM/rstar4d/models/stam.py) · [Stage I 到 II 的权重迁移](../../../../RSTAR-STAM/rstar4d/models/model.py)

## 任务 7　验证续训、显存与交付入口

- [x] 在 `rstar_decnn/checkpoint.py` 保存架构、权重、上游摘要、SAM 初始化来源、双先验来源、`g`、网格、相位标签、划分及 `α`。断点另存当前阶段、转段标志、优化器分组、调度器、AMP、随机与采样状态、历史最佳模型。冻结主干可用可核验的源文件引用。所有已更新的组都随产物保存。加载时检查摘要与配置。

- [ ] 最终交付四份训练配置、分支和续训的回归测试、可核验的三支预测索引、两个标定系数及四组主对照与 DeCNN 单支的配对结果表。分别记录工程通过、留出结果与资源成本。真实权重、投影或左室标注不足的项目记明缺项与受影响终点。
