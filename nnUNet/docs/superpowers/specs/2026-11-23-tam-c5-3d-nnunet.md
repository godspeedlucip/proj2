# 3D nnU-Net 心脏 CT 分割的 TAM C5 规格

## 1. 目标与范围

在本仓库的 nnU-Net v2.6.2 `3d_fullres` 上实现论文的 C5 插入配置。每次采集有 10 期三维心脏 CT，其中 `phase1` 和 `phase5` 有人工分割掩膜。首轮用这两期成对训练和推理，为每期生成一份三维分割。

论文在二维 CAMUS 上将 C5 定义为在 `E3 + E4 + E5` 插入 TAM。本文按论文算法 1 将三个模块接入编码阶段输出，并迁移到三维 CT。阶段通道、空间卷积核和步长来自本项目的 nnU-Net plans。第一轮用 C1、C3、C4、C5 比较插入位置。训练和推理的验收范围为单卡 `3d_fullres`、单通道 CT 和互斥类别掩膜。[TAM 论文图 2、表 1、算法 1 和算法 2](https://doi.org/10.1016/j.media.2026.103981)

`phase1` 和 `phase5` 沿用数据中的时相标识。首轮以 `T=2` 复现论文表 1 对输入帧数的控制，输出和性能结论覆盖这两期。第 2.5 节定义如何加入另外八期的真实图像并生成对应分割。

## 2. 数据与预处理

### 2.1 样本与划分

每条数据记录包含 `case_id`、`patient_id`，以及 `phase1`、`phase5` 的图像文件和掩膜文件。一个 `case_id` 对应一次采集。两期按固定顺序 `[phase1, phase5]` 装载。预测输入使用同样的记录结构，只需提供两期图像。数据清单显式记录文件路径与时相，避免依赖导出文件的排序。数据路径、标签映射和实际病例划分由项目提供。

以 `patient_id` 为单位生成训练、验证和测试划分。一个患者有多次采集时，所有采集进入同一个集合。数据准备时检查病例标识唯一、文件齐全、图像配对正确、掩膜类别符合 `dataset.json`。训练前检查各集合的患者交集为空。对照组共用同一份患者划分。

### 2.2 空间几何与 CT 归一化

- 检查原始体积的方向、原点、间距和尺寸，以及每期图像与其掩膜的物理几何。两期几何一致时直接堆叠。其余病例使用物理坐标变换将 `phase5` 重采样至 `phase1` 网格，图像用连续插值，硬标签用最近邻，并分别保存两期原始几何。流程只依赖影像几何，保留实际心脏形变。
- 两期共用 nnU-Net 的轴转置、裁剪框和目标间距。共同裁剪框由重采样后两期图像的联合有效范围确定。用随各源图像网格变换的视野掩膜检查两期均覆盖该裁剪框。带标签时再检查两期人工标注的前景都被裁剪框覆盖。检查失败时报告 `case_id` 和时相并暂停该病例处理，待人工核查几何。这样训练与推理采用同一个几何条件，视野外的重采样填充值不会混入监督区域。
- 从训练患者的两期前景估计一套 CT 强度统计，供两期和所有对照组共用。验证和测试复用训练统计。沿用 plans 的 CT 归一化、目标间距和空间重采样函数；成对预处理入口负责对两个时相应用这些设置。
- 在独立的预处理目录中保存成对体积，路径由 dataset、plans 和实验折标识区分。复用 `nnUNetDatasetNumpy.save_case` 的存储格式。每例的 `<case_id>.npz` 包含 `data` 和 `seg`，形状均为 `[T, D, H, W]`，`<case_id>.pkl` 保存时相标识、共同网格、两期原始几何和前景采样点。保留该折的 `dataset_fingerprint.json`、`dataset.json` 与 `splits_final.json`，供 trainer 初始化和训练启动读取。训练、推理使用相同的图像预处理顺序。预测的裁剪和归一化只读图像及冻结的训练统计。

### 2.3 Patch 采样和增强

从两期体积的**同一空间位置**取一个成对 patch。前景过采样的候选点来自两个有标注时相的前景并集。两个图像及其掩膜使用同一套随机空间变换和裁剪位置，标签插值保持离散。组间固定增强设置。加载器批量形状如下。

| 数据 | 形状 |
|---|---|
| 输入图像 | `[B, T, 1, D, H, W]`，首轮 `T=2` |
| 硬标签 | `[B, T, 1, D, H, W]` |
| 每个监督尺度的 logits | `[B, T, K, D_s, H_s, W_s]` |

`B` 是成对样本数，`K` 由 nnU-Net 的 `LabelManager` 决定。若启用深监督，标签跟随 logits 的尺度列表，每个尺度都保留时相轴和类别轴。

### 2.4 固定对照实验的 Patch 大小

**同一组 C1、C3、C4、C5 对照共用一份定稿的 `3d_fullres` plans。** 先用训练数据生成参考 plans，取其中的 `patch_size` 作为候选。默认 planner 依据目标间距、数据形状和空间主干的显存估计挑选候选大小。TAM 的显存开销用实测补充。在同一配置下重复训练时，随机变化的是 patch 的位置和增强参数，送入网络的空间尺寸由 plans 固定。[默认 planner 的显存估计](../../../nnunetv2/experiment_planning/experiment_planners/default_experiment_planner.py#L94)

1. 用正式训练的精度、深监督配置和两期输入，对 C5 做完整训练步的显存预试，覆盖前向、反向和优化器状态分配。显存不足时，先尝试减小所有对照共用的成对 batch size，再考虑缩小空间 patch，以尽量保留每个 patch 覆盖的物理视野。
2. 如需缩小 patch，维持参考 plans 的目标间距和主干拓扑，确保各轴尺寸可被该轴累计下采样步长整除，并检查最深层和解码跳接的形状。用 C1、C3、C4、C5 各验证一次候选设置下的训练和滑窗推理，再锁定 `patch_size`、`batch_size`、间距和编码器步长。四组用相同的成对样本数定义 batch。
3. 训练以定稿 plans 为唯一来源。增强开始时可使用内部派生的 `initial_patch_size` 来容纳旋转，增强后的模型输入统一裁回 `patch_size`。整卷验证和独立推理使用同一尺寸作为滑窗 tile，并固定滑窗步进和镜像策略。[nnU-Net 训练裁剪设置](../../../nnunetv2/training/nnUNetTrainer/nnUNetTrainer.py#L434) · [nnU-Net 滑窗设置](../../../nnunetv2/inference/predict_from_raw_data.py#L506)
4. 保存定稿 plans 的标识和副本，并在启动、恢复和预测时核对实际 patch、间距及主干步长。使用一个预先固定的训练、验证、测试划分时，所有重复实验复用同一份 plans。若严格交叉验证给每折用该折训练患者独立规划，允许折间 patch 不同，四个配置在**同一折内**必须共用 plans，结果先按折配对比较再汇总。正式实验中若必须改 patch 或 batch，生成新版本并用新设置重跑该组四个配置。

### 2.5 用两期标注训练其他时相的分割

保留 `T=2` 作为插入位置对照。单独定义三期稀疏监督配置，固定输入顺序为 `[phase1, phase5, query_phase]`。每次从同一采集的另外八期中选一个 `query_phase`，用该期的真实 CT 与两期参考 CT 在共同网格取同位置 patch。训练采样覆盖全部八个目标时相。网络对三期都产生 logits，损失仍由 `phase1` 和 `phase5` 两期等权平均。数据以时相标识关联已有标签，`query_phase` 只读图像。由于跨帧注意力参与计算，两个有监督输出的损失也可以经由目标时相特征更新模型参数。

预测某一期时用同一个三期模型输入 `[phase1, phase5, 该期]`，导出第三个输出。遍历八个目标时相即可得到八份分割。需要同一 checkpoint 产生全部十期结果时，预先固定一组（例如以 `phase3` 为目标的组合）并从该组保留 `phase1` 和 `phase5` 的预测。各期都在各自原始网格导出。推理输入均为 CT 图像。

在 `prepare` 中用 `--context-phases` 将目标时相列表写入预处理 plans。预处理、模型输入校验、标签索引、checkpoint 和滑窗导出均使用这份配置，三期模式单独训练。对比 `T=2` 和 `T=3` 时共用可运行的 patch、间距、划分和训练预算。额外时相的分割精度用独立人工掩膜验证。每个 TAM 的有序帧对数为 `T×(T−1)`，所以扩展模式用三期一组，逐一覆盖另外八个时相。[运行步骤](../../../documentation/paired_tam_ablation.md)

论文表 2 给出了多帧输入、仅 ED 和 ES 参与损失的稀疏监督设置。作者 GitHub 的默认 Notebook 则加载 ED、ES 和三个中间帧的图像与掩膜，对所有加载帧累加损失。公开 Notebook 用二维 FCN8s，在瓶颈执行一次 TAM。三期稀疏监督的损失按论文设置实现，三维编码阶段的插入位置按论文 C5 实现。[TAM 论文表 1、表 2](https://doi.org/10.1016/j.media.2026.103981) · [作者的 FCN8s Notebook](https://github.com/kamruleee51/TAM/blob/main/codes/TAM_FCN8s.ipynb) · [作者的数据加载器](https://github.com/kamruleee51/TAM/blob/main/codes/data_loader.py)

## 3. C5 编码器和 TAM3D

### 3.1 编码阶段

从现有 plans 构建 3D 卷积 U-Net。首轮以默认 `PlainConvUNet` 为验收架构。对包含 `L` 个 stage 的编码器，以零起始编号在 `L-3`、`L-2` 和 `L-1` 的**卷积块输出后**插入 TAM。六阶段时对应 `stage 3、4、5`。

| 配置 | 有 TAM 的编码阶段 |
|---|---|
| C1，同一数据路径的逐时相对照 | 无 |
| C3 | `L-1` |
| C4 | `L-2, L-1` |
| C5 | `L-3, L-2, L-1` |

编码和解码时，将 `B,T` 合并到 batch 维，让空间卷积按时相共享权重。每次到 TAM 前恢复 `[B,T,C,D,H,W]`，在每个病例内部做跨时相交互。随后再合并 `B,T`。中间编码 stage 的增强输出既喂给下一编码阶段，也存入本级跳跃连接。最深 stage 的增强输出进入解码器。解码器逐时相调用同一组参数，并将每个尺度的 logits 恢复成带时相轴的输出。

修改点在编码器的 stage 循环内部。每个 stage 先做本级空间卷积，再按配置做 TAM，再保存本级输出。这样 `E3` 的增强结果会参与 `E4` 卷积，`E4` 的增强结果会参与瓶颈卷积。

### 3.2 模块内部

每个插入位置按 stage 输出通道 `C` 初始化独立的 `TAM3D` 实例，同一位置的参数由所有时相共享。首轮使用 8 个头，嵌入宽度取本级 `C`。模型构建时检查宽度能否被 8 整除。需要覆盖默认宽度时，在独立实验 plans 的 `architecture.arch_kwargs.tam.embed_dim_by_stage` 中用零起始 stage 索引显式指定。trainer 和预测入口均在建网前从同一份 plans 读此配置，并在构建空间主干前从传入主干的参数中取出 TAM 专用字段。模块最终投影回 `C`。

1. 对每个目标时相 `i`，依次处理每个参考时相 `j ≠ i`。按论文定义，`j` 提供 Query，`i` 提供 Key 和 Value。展平空间网格为 `N=D×H×W` 个 token，Q、K、V 的形状为 `[B, heads, N, head_dim]`，对 Key 的空间 token 维做 softmax。每个病例独立计算。
2. 拼接各注意力头并恢复成 3D 网格。用保持嵌入宽度的逐点 `Conv3d + Sigmoid` 产生门控权重，逐元素应用到注意力特征。
3. 将门控后的特征和目标时相原特征沿通道拼接。用保持空间尺寸的 `3×3×3` 卷积、ReLU 和 BatchNorm3d 融合。本步骤按附录算法 2 的顺序实现。
4. 对该目标时相的所有参考贡献取平均，用 `1×1×1` 卷积投影，返回与输入相同的 `[B,T,C,D,H,W]`。两帧时，每个目标时相只有一个参考时相。

使用 PyTorch 缩放点积注意力接口，按有序时相对计算。每个 stage 的空间注意力规模随 `N²` 增长。按第 2.4 节确定共有的 patch 和 batch 大小，记录 C5 的实测峰值显存和每步耗时。

| 接入点 | 约定 |
|---|---|

| [`_build_loss`](../../../nnunetv2/training/nnUNetTrainer/nnUNetTrainer.py#L398)、[`train_step`](../../../nnunetv2/training/nnUNetTrainer/nnUNetTrainer.py#L980) 和 [`validation_step`](../../../nnunetv2/training/nnUNetTrainer/nnUNetTrainer.py#L1027) | 按时相从全部监督尺度取出对应的 logits 和 target。每期分别计算现有 Dice + CE 及其深监督损失，再对两期损失取算术平均。启用 `batch_dice` 时，每期独立汇总各病例的交并统计。在线验证继续产生基础 trainer 所需的损失及前景统计，同时记录分时相指标。 |
| [`perform_actual_validation`](../../../nnunetv2/training/nnUNetTrainer/nnUNetTrainer.py#L1225) 和 [滑窗预测](../../../nnunetv2/inference/predict_from_raw_data.py#L506) | 成对验证使用同一个独立的成对预测入口。复用现有滑窗位置计算和高斯加权函数，由成对预测器维护 `[T,K,D,H,W]` 的累积缓冲区。默认单掩膜预测器按 `[K,D,H,W]` 分配输出，因此 trainer 的整卷验证和成对推理都接到专用入口。 |
| [预测导出](../../../nnunetv2/inference/export_prediction.py#L14) | 每期单独融合滑窗 logits。恢复共同网格的裁剪和轴顺序后，映射到该期原始物理几何，再用 `LabelManager` 生成标签图。输出按 `case_id` 和时相标识命名，每个病例生成两份预测。 |

推理时，同一个滑窗坐标一次读取两期 patch 并一次前向产生两份 logits。若启用镜像测试增强，两期同时翻转相同的空间轴。checkpoint 重载后关闭深监督，预测器使用原生几何中的 phase1、phase5 输出分别评分。

## 5. 对照实验与验收

**主实验。** 按患者固定划分，在相同 CT 统计、patch、增强、训练预算和有标注时相下比较 C1、C3、C4、C5。按患者、时相和解剖结构分别报告 Dice、HD95（mm），附两期聚合结果、典型失败病例、参数量及峰值显存。HD95 是本项目预定的边界指标，论文表 1 报告的是 HD。C5 的收益由 CT 测试结果决定。

**实现验收。**

1. 用合成的成对三维 patch 跑完整前向和反向。检查 C5 恰好在三个目标 stage 执行，三处模块都有梯度，每个输出位置与输入时相一一对应。训练状态检查所有深监督尺度，推理状态检查最高分辨率输出。
2. 用两个病例组成一个测试 batch。只改变第一个病例的参考时相，在 `eval` 模式验证其输出能受跨时相特征影响，同时第二个病例的输出保持一致。关闭 TAM 的 C1 在相同形状与权重下应与独立逐时相推理一致。
3. 用已知坐标点或合成掩膜验证两期共用增强和滑窗位置，并能逆变换到各自原始几何。检查两份导出的掩膜文件及其尺寸、间距、方向、原点和时相名称。
4. 用一个小型患者划分走通数据准备、训练、checkpoint 重载、整卷验证和独立成对预测。对照日志中记录实际 plans、数据划分、插入层索引、训练 patch、推理 tile、成对 batch 大小及两期指标。检查同一折内四组的 `patch_size`、`batch_size` 和间距相等。普通 nnU-Net 训练入口在原有任务上的行为通过现有路径验证。
5. 记录覆盖范围。首轮只报告 phase1、phase5。若后续补做其他时相的实验，只在独立病例中用新增人工掩膜量化这些时相的分割精度。
